# Sindhupath Merchant Navy Academy

Welcome to the updated web application for the **Sindhupath Merchant Navy Academy**. This project provides a premium, responsive, and highly interactive landing page utilizing Tailwind CSS.

## Features Implemented

1. **Interactive Mobile Navigation Drawer**:
   - Collapsible drawer menu designed for mobile screen widths, toggled dynamically.
2. **Glassmorphic Lead Capture Modal**:
   - Replaced redirects to Google Forms with a smooth inline registration modal for booking or enquiries, enhancing user retention.
3. **Interactive FAQ Accordions**:
   - Smooth slide-down and rotate-on-click accordions to answer key questions (such as IMU-CET details and eligibility).
4. **Smooth Section Scroll Navigation**:
   - Internal anchor links mapped from the main navigation menu direct users to the appropriate parts of the single-page application.
5. **Staggered Reveal Animations**:
   - Upgraded scroll-animations using `IntersectionObserver` to trigger fade-in transformations seamlessly.
6. **Premium Glow & Micro-interactions**:
   - Golden visual cues and button animations that elevate the page's maritime luxury aesthetic.

## How to Run

1. Open this directory `sindhupath-academy/` in your IDE.
2. Open `index.html` directly in any web browser, or launch it with a local development server such as VS Code's "Live Server" extension or through CLI tool options like:
   ```bash
   npx browser-sync start --server --files "*.html"
   ```
